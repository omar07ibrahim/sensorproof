# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-08-10

### Added

- strict, bounded JSON scenario and artifact formats;
- deterministic integer motion and multi-sensor simulation;
- fault-aware fixed-gain state estimation with innovation gating and quarantine;
- identical ungated counterfactual baseline;
- independently replayable transition and SHA-256 certificate verification;
- run, verify, inspect, and offline-report CLI commands;
- adversarial tamper, compatibility, coverage, wheel, and installed-CLI tests;
- hash-locked quality and browser-capture environments;
- source-bound real CLI, HTML, SVG, PNG, and GIF portfolio evidence;
- architecture, scenario, evidence, security, and contribution documentation.

### Known boundaries

- release evidence covers one abrupt synthetic GNSS bias-step;
- slow ramps, correlated faults, dropouts, live hardware, calibrated covariance, and safety use remain out of scope.
