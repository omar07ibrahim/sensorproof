# Architecture

SensorProof is deliberately small enough to audit end to end. Its primary design goal is not maximum estimator sophistication; it is a reproducible fault-isolation decision whose complete causal path can be inspected and replayed.

![Generation and verification architecture](evidence/architecture.svg)

## State and units

The state is `[x_mm, y_mm, vx_mm_s, vy_mm_s]`. Every state, observation, residual, gain application, metric input, and trace field is an integer.

For a timestep `dt_ms`, prediction is:

```text
x' = x + round(vx * dt_ms / 1000)
y' = y + round(vy * dt_ms / 1000)
vx' = vx
vy' = vy
```

`round` means symmetric half-away-from-zero integer division implemented in one shared primitive.

A position sensor updates position with `alpha_milli / 1000` and velocity with `beta_milli / dt_ms`. A velocity sensor updates velocity with `alpha_milli / 1000`. The update path never uses binary floating point.

## Innovation decision

For a two-axis observation `z` and the relevant predicted components `h(x')`:

```text
r = z - h(x')
residual_sq = r_x² + r_y²
gate_radius = round(noise_units * gate_sigma_milli / 1000)
gate_limit_sq = 2 * gate_radius²
```

The robust run rejects a measurement when `residual_sq > gate_limit_sq`. Two consecutive rejections place that sensor into a three-observation quarantine. A quarantined observation is recorded but does not update the state. Acceptance resets the rejection streak.

The baseline runs the same prediction and update equations with the same observation ordering and gains, but disables rejection and quarantine. This isolates the contribution of the fault policy in the included experiment.

## Deterministic simulator

Truth follows a piecewise-constant acceleration schedule. Noise is generated by hashing:

```text
seed | step | sensor_id | axis
```

Six 16-bit values from SHA-256 are centered and scaled with integer division. This is a bounded Irwin-Hall-like perturbation, not a claim of calibrated Gaussian sensor noise. Faults are applied after noise so their exact injected bias is recorded in the synthetic ground truth.

## Artifact

The artifact contains:

- the canonical validated scenario and its SHA-256 digest;
- all truth frames and observations;
- robust and baseline traces;
- each decision's before-state, residual, gate, status, after-state, and cooldown;
- independently reproducible summaries and comparison;
- observation, robust-trace, baseline-trace, and payload digests.

The pretty-printed JSON file is for review. Digests use a separate canonical JSON encoding with sorted keys, no insignificant whitespace, strict UTF-8, and non-finite numbers disabled.

## Verification trust boundary

Generation and verification share schema definitions and integer primitives, but the verifier does not call the filter runner. It:

1. parses the embedded scenario through the strict schema;
2. regenerates all synthetic observations;
3. predicts state independently;
4. recomputes residuals, squared norms, gate values, status, health counters, and updates;
5. recomputes errors, summaries, winner, and reduction;
6. verifies the four SHA-256 digests.

This catches both accidental drift and direct artifact tampering. The adversarial test suite mutates observations, residuals, statuses, summaries, comparison labels, root keys, and certificates.

## Complexity

For `T` steps and `S` sensors:

- simulation: `O(TS + TF)`, where `F` is the bounded fault count;
- one filter: `O(TS)`;
- verification: `O(TS)`;
- artifact memory: `O(TS)`.

Input budgets cap `T ≤ 2,000`, `S ≤ 16`, `F ≤ 64`, scenario size at 256 KiB, and artifact size at 16 MiB.

## Failure modes intentionally outside v0.1.0

- slow or sub-threshold bias ramps;
- faults in the configured low-noise reference sensor;
- correlated or simultaneous sensor compromise;
- unmodelled timestamp drift and out-of-order messages;
- calibrated uncertainty propagation;
- real-time scheduling and backpressure;
- live hardware transport and actuation.

These boundaries are part of the release contract, not hidden caveats. See [Scenario and claims](scenario.md).
